# Mi aula de Office (Writer · Calc · Base)

Web pública y gratuita con 34 ejercicios, respuestas, mini-examen y que permite subir PDFs.

## Archivos

- `index.html` — página principal (la que abre la URL pública).
- `Portal_Ejercicios.html` — copia idéntica para abrirla también en local.
- `ejercicios.js` — catálogo de ejercicios y respuestas. **Aquí es donde se añaden ejercicios nuevos.**
- `Ejercicios_Writer_Calc_Base.pdf` — cuaderno original, se abre desde «Mis PDFs».
- `Abrir_Mi_Aula.bat` — acceso directo solo para Windows (no hace falta en la web pública).

## Cómo actualizar los ejercicios

1. Sustituir `ejercicios.js` por la versión nueva.
2. Subir el archivo al repositorio (GitHub → `Add file` → `Upload files`, o desde el ordenador con `git`).
3. En 1–2 minutos la web muestra los ejercicios nuevos al pulsar F5.

No hace falta tocar `index.html`.

## Privacidad

Cada visitante guarda **sus progresos y sus PDFs en su propio navegador**. No se comparten entre personas y no hace falta iniciar sesión. Si alguien borra los datos de su navegador, perderá sus archivos locales: puede usar el botón «Descargar» para hacer copias.
